Defense-in-Depth Architecture

Layer 1: Secure Boot

UEFI Secure Boot with Shim bootloader, GPG-signed kernel and initramfs

Layer 2: Early Boot Hardening

Dracut initramfs with LUKS2 disk encryption, Argon2i key derivation

Layer 3: Kernel Hardening

ASLR, stack canaries, DEP/NX, SMEP, SMAP, strict kernel RWX

Layer 4: Mandatory Access Control

SELinux enforcing mode with MAYOTIX custom policies

Layer 5: Service Hardening

27+ systemd hardening directives per service (ProtectSystem, ProtectHome, CapabilityBoundingSet)

Layer 6: Filesystem Security

LUKS2 home partition, immutable system root (Silverblue pattern)

Layer 7: Application Sandboxing

Flatpak containerization for untrusted applications

Layer 8: Audit & Logging

systemd-journald with persistent logging, auditd integration

Layer 9: Update Integrity

Image-based atomic updates with GPG signing and reproducible builds
